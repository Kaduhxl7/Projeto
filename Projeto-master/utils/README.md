# 🛠️ Utilitários do Projeto

Esta pasta contém arquivos auxiliares e de desenvolvimento do DressCode.

## 📁 Arquivos

### Configuração e Setup
- `configurar.php` - Script de configuração automática do projeto
- `setup-db.php` - Configuração do banco de dados
- `setup-quick.php` - Setup rápido do projeto
- `expand-database.php` - Expansão do banco de dados

### Testes e Diagnósticos
- `test-db.php` - Teste de conexão com banco de dados
- `test-connection.php` - Teste de conectividade
- `check-files.php` - Verificação de arquivos do projeto

### Exemplos e Documentação
- `exemplo-uso-repository.php` - Exemplo de uso do padrão Repository

## 🚀 Como usar

### Testar conexão do banco:
```
http://localhost:8000/utils/test-db.php
```

### Verificar arquivos do projeto:
```
http://localhost:8000/utils/check-files.php
```

### Ver exemplo do Repository:
```
http://localhost:8000/utils/exemplo-uso-repository.php
```

## ⚠️ Importante
Estes arquivos são para desenvolvimento e manutenção. O funcionamento principal do projeto não depende deles.
