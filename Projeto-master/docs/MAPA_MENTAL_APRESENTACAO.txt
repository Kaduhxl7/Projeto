                          🎯 PADRÕES GOF DETALHADOS


    ┌─────────────────────────────────────────────────────────────────┐
    │                                                                 │
    │  🔧 SINGLETON                                                   │
    │  ├─ Arquivo: DatabaseConnection.php                            │
    │  ├─ Problema: Múltiplas conexões desperdiçam recursos          │
    │  ├─ Solução: Instância única de PDO                            │
    │  └─ Benefício: Performance + Controle                          │
    │                                                                 │
    └─────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────┐
    │                                                                 │
    │  🏭 FACTORY METHOD                                              │
    │  ├─ Arquivo: ProductFactory.php                                │
    │  ├─ Problema: Criar diferentes tipos de produtos               │
    │  ├─ Solução: Factory centralizada                              │
    │  ├─ Tipos: Novo, Usado, Promocional, Vintage                   │
    │  └─ Benefício: Extensibilidade sem modificar código            │
    │                                                                 │
    └─────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────┐
    │                                                                 │
    │  👁️ OBSERVER                                                    │
    │  ├─ Arquivos: observers/                                       │
    │  ├─ Problema: Notificações acopladas ao código                 │
    │  ├─ Solução: Padrão Observer                                   │
    │  ├─ Eventos: new_product, promotion, store_update              │
    │  └─ Benefício: Sistema desacoplado e extensível                │
    │                                                                 │
    └─────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────┐
    │                                                                 │
    │  🎯 STRATEGY + DECORATOR                                        │
    │  ├─ Arquivos: search/                                          │
    │  ├─ Problema: Busca inflexível                                 │
    │  ├─ Solução: Strategy define contexto, Decorator adiciona      │
    │  ├─ Decorators: 8 filtros (categoria, preço, cor, etc.)        │
    │  └─ Benefício: Filtros dinâmicos aplicados no SQL              │
    │                                                                 │
    └─────────────────────────────────────────────────────────────────┘


═══════════════════════════════════════════════════════════════════════════════


                        🔄 FLUXO DE UMA REQUISIÇÃO


    ┌─────────────┐
    │   USUÁRIO   │  Busca: "vestido vermelho < R$100"
    └──────┬──────┘
           │
           ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  CONTROLLER (ProductController)                             │
    │  ├─ Recebe requisição HTTP                                  │
    │  ├─ Extrai filtros: cor=vermelho, preco_max=100             │
    │  └─ Coordena fluxo                                          │
    └──────┬──────────────────────────────────────────────────────┘
           │
           ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  SINGLETON (DatabaseConnection)                             │
    │  └─ Retorna conexão PDO única                               │
    └──────┬──────────────────────────────────────────────────────┘
           │
           ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  REPOSITORY (ProductRepository)                             │
    │  └─ Recebe conexão Singleton                                │
    └──────┬──────────────────────────────────────────────────────┘
           │
           ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  STRATEGY (BuscarProdutosStrategy)                          │
    │  ├─ Aplica Decorators:                                      │
    │  │  ├─ FiltroCorDecorator("vermelho")                       │
    │  │  └─ FiltroPrecoMaxDecorator(100)                         │
    │  └─ Compõe SQL dinamicamente                                │
    └──────┬──────────────────────────────────────────────────────┘
           │
           ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  REPOSITORY executa SQL                                     │
    │  SELECT * FROM produtos                                     │
    │  WHERE cor = 'vermelho' AND preco <= 100                    │
    └──────┬──────────────────────────────────────────────────────┘
           │
           ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  FACTORY (ProductFactory)                                   │
    │  └─ Cria objetos Product tipados                            │
    └──────┬──────────────────────────────────────────────────────┘
           │
           ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  VIEW (products/search.php)                                 │
    │  └─ Renderiza HTML com resultados                           │
    └──────┬──────────────────────────────────────────────────────┘
           │
           ▼
    ┌─────────────┐
    │   USUÁRIO   │  Vê resultados filtrados
    └─────────────┘
